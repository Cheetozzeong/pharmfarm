# 초과 처방 입고 재고 해소 가이드

## 이 안내가 표시되는 이유

처방 당시 재고가 부족했거나 아직 시스템에 재고가 등록되지 않았던 약품과 동일한 보험코드의 약품이 입고되면 `초과 처방 연결 후보` 안내가 표시됩니다.

이 안내는 시스템이 연결 가능한 항목을 찾았다는 뜻입니다. **안내가 표시된 것만으로 재고가 줄어들지는 않습니다.** 약사가 처방전, 실제 조제 여부와 수량을 확인하고 최종 확정해야 재고가 감소합니다.

## 입고 완료 화면에서 확인할 내용

입고 완료 화면에 다음 안내가 표시될 수 있습니다.

> 입고 재고와 연결할 초과 처방이 있습니다. 재고는 아직 차감하지 않았습니다.

안내에는 다음 정보가 표시됩니다.

- 약품명
- 과거 처방의 부족 수량
- 현재 입고 재고에서 차감 가능한 수량

`초과 처방 확인`을 누르면 확인이 필요한 첫 번째 처방으로 이동합니다.

## 실제 재고를 차감하는 순서

1. `초과 처방` 화면에서 `입고 재고 확인 필요` 표시가 있는 항목을 선택합니다.
2. 처방전 번호, 처방일시, 약품명과 보험코드가 실제 조제 내역과 일치하는지 확인합니다.
3. `입고 재고 확인`을 누릅니다.
4. 부족 수량과 현재 동일 보험코드 재고를 비교합니다.
5. 이번에 해소할 수량을 `-`, `+` 또는 수량 입력란으로 선택합니다.
6. 화면에 표시되는 두 가지 예상 결과를 확인합니다.
   - 처리 후 현재 재고
   - 처리 후 남는 초과 처방 수량
7. `차감 내용 확인`을 누릅니다. 이 단계까지는 재고가 감소하지 않습니다.
8. 최종 확인 화면에서 처방전과 실제 조제 여부를 다시 확인합니다.
9. `{수량}개 차감 확정`을 눌러 처리합니다.

확정되면 재고가 즉시 감소하며 처리 계정, 처리 시각, 처방전과 차감 수량이 이력에 기록됩니다.

## 수량 선택 기준

- 실제로 조제되었고 아직 시스템 재고에 반영되지 않은 수량만 선택합니다.
- 부족 수량 전체를 한 번에 처리할 필요는 없습니다. 현재 입고된 수량만 부분 처리할 수 있습니다.
- 선택 가능한 최대 수량은 `남은 부족 수량`과 `현재 동일코드 재고` 중 작은 값입니다.
- 동일 보험코드가 아닌 약품은 입고 재고 해소에 사용할 수 없습니다. 다른 약품으로 처리하려면 `대체 약품 처리`를 사용합니다.

## 상태별 의미

| 표시                | 의미                                    | 약사가 할 일                              |
| ------------------- | --------------------------------------- | ----------------------------------------- |
| 주문 필요           | 부족분이 아직 확보되지 않음             | 주문 또는 재고 확보 여부 확인             |
| 주문 완료           | 주문은 했지만 부족분 처리가 끝나지 않음 | 입고 후 동일코드 재고 확인                |
| 입고 재고 확인 필요 | 현재 재고로 일부 또는 전체 해소 가능    | 처방과 수량 확인 후 직접 차감             |
| 보류                | 의도적으로 처리를 중단한 상태           | 먼저 주문 필요 또는 주문 완료로 상태 변경 |
| 대체 처리           | 다른 약품 재고로 처리 완료              | 추가 차감하지 않음                        |
| 해소 완료           | 부족 수량이 모두 처리됨                 | 처리 이력만 확인                          |

## 꼭 주의할 사항

- 입고 알림만 확인하고 종료해도 재고는 차감되지 않습니다.
- 실제 조제 여부가 불확실하면 차감하지 말고 `보류` 상태로 두십시오.
- 다른 처방전의 부족분과 혼동하지 않도록 처방전 번호와 처방일시를 반드시 확인하십시오.
- 브라우저를 여러 창에서 동시에 열어 처리하지 마십시오. 최종 확정 시 서버가 재고를 다시 검사하지만, 같은 항목을 동시에 처리하면 다른 창에는 새로고침 안내가 표시될 수 있습니다.
- 최종 확정 버튼을 연속해서 누르거나 통신이 지연되어 같은 요청이 다시 전달되어도 동일 요청으로 식별해 중복 차감을 막습니다. 처리 결과가 바로 보이지 않으면 버튼을 반복해서 누르지 말고 화면을 새로고침해 이력을 확인하십시오.
- 차감 후에는 입고 이력의 반품 가능 여부와 실제 약품 보유 상태도 함께 확인하십시오.

## 잘못 차감했거나 수량이 맞지 않을 때

추가 처리를 반복하지 말고 관리자에게 다음 정보를 전달하십시오.

- 약국명
- 처방전 번호
- 약품명과 보험코드
- 차감한 수량
- 처리한 대략적인 시각
- 화면에 표시된 오류 메시지 또는 캡처

관리자는 `PRESCRIPTION_ARRIVAL_RECONCILE` 차감 이력과 처리 계정을 기준으로 확인할 수 있습니다. 임의로 재고 수량만 되돌리면 처방 처리 이력과 재고 이력이 달라질 수 있으므로 반드시 관리자 확인 후 정정하십시오.

## 예시

처방 당시 아드반탄연고 1개가 부족했고 다음 날 동일 보험코드 재고 1개가 입고된 경우:

1. 입고 완료 화면에 초과 처방 연결 후보 1건이 표시됩니다.
2. 이 시점의 재고는 1개이며 아직 감소하지 않았습니다.
3. 약사가 처방전과 실제 조제를 확인하고 1개 차감을 확정합니다.
4. 현재 재고는 1개에서 0개로 변경됩니다.
5. 초과 처방 부족 수량은 1개에서 0개로 변경되고 해소 완료 처리됩니다.
